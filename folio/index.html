Folio

Folio is a local-first PDF editor for iPhone, Android and the web. Open PDFs, organise pages, edit the text already on a page, redact what should not be there, recognise text on a scan, add text, drawings, shapes, images and visual signatures, then export a new PDF — or a Word or Excel file — all on your own device.

Most PDF tools upload your document to a server to do their work. Folio does not. Rendering, editing and writing the new PDF all happen on the device in front of you; the app has no account, no backend and no network code. The Android version does not even request the Internet permission.

Password-protected PDFs open once you supply the password, which is used and discarded, and an export can be protected again on the way out. The same design, tools and warnings are shared across all three versions, so a document behaves the same way wherever you open it.
