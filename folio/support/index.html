Support

Write to support@apsoluts.com. Tell us what you were doing and what happened instead. There is no account to look up, so whatever you can describe is what we have to go on. If a particular file misbehaves and you are comfortable sharing it, attach it — we never see your documents otherwise.

Common questions

Does my document leave my device?

No. Rendering, editing and export all happen on the device. The app has no server and no network code; the Android version does not even ask for the Internet permission. Details are in the Privacy Policy.

Did Folio change my original file?

No. Export always writes a new PDF and asks you where to put it. The file you opened is untouched.

It will not open my PDF.

Folio checks the contents of a file, not its name, so a file that is not really a PDF is refused. A damaged file may also be refused, with the reason given.

It is asking for a password.

The file is protected, and Folio needs the password that opens it — either the one for opening or the owner's password. It checks what you type against the file itself; it cannot recover, guess or bypass a password, and neither can we. The password is used to open the document and then discarded: it is never stored, never saved with a draft, and never written into a file you export unless you ask for protection there too. A file protected with a certificate rather than a password needs the tool that issued the certificate.

Can I put a password on a file I export?

Yes — Protection in the export dialog. You can set the password that opens the file, an owner password, and what a reader may do without it. The file is encrypted with AES-256. Keep the password somewhere safe: if you lose it, we cannot get the file back for you. Exporting a document that arrived protected without setting a new password is allowed, but the app warns you first, because the result is open to anyone.

Is redaction really permanent?

The marked text is deleted from the page rather than covered, and an image or form overlapping the marked area is removed with it. It acts on what you marked on the page; it does not hunt for the same information elsewhere in the document. Check the exported file before you hand it to anyone.

The recognised text on my scan is wrong.

Recognition runs on your device and does its best with the image it is given. Handwriting, faint or skewed scans, tables and unusual type all cost accuracy. The invisible text layer exists so the page can be searched and copied — the image is still what the page says.

My Word or Excel file does not look like the PDF.

It is not meant to. A conversion carries the text, its styling and its reading order, and turns detected tables into real ones; the page layout, images, drawings, annotations and exact positions stay behind. Export a PDF when the document has to look as it does now. A scanned page contributes nothing until you have run recognition on it.

Something looks different after export.

The review step before export lists anything the app could not reproduce exactly — an unusual font, a form field, an annotation from another producer. Check that list. If the output still differs from what you expected, tell us which page and what changed.

I closed the app and lost my work.

Draft recovery is off by default so nothing is stored without your say-so. Turn it on in Settings and the working document is saved automatically a moment after each change; the home screen then offers to recover it. It cannot recover work done before it was switched on.

Is a signature in Folio legally binding?

Folio places a picture of your signature on the page. It does not create a certified digital signature. Whether an image signature is sufficient depends on the law where you are and on what the other party accepts.

How do I delete everything?

Settings → Delete all drafts removes any saved drafts. Deleting the app (or, on the web, clearing this site's data in your browser) removes everything else it stored. Files you exported are wherever you saved them and are not affected.
