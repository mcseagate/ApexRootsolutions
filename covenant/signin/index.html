How sign-in works

Phone number, then a six-digit code

Covenant is a marriage-intent dating app for adults. Every member signs in with a phone number, and that number is confirmed with a one-time code sent by text message. The app is on iOS and Android; this page walks through the same two steps so you can see what is asked and what is sent.

The steps

  1. Enter your number. The member picks a country and types a phone number. The app says: “We’ll send a six-digit code to confirm it.”
  2. Receive the code. One text message arrives. It contains the code and nothing else: no marketing, no link.
  3. Enter the code to continue. Without the correct code the member cannot go any further. The code expires, can be requested again only after a short wait, and is limited in the number of tries.

What is sent, and why

  • The message: “Your Covenant verification code is 123456. Do not share it with anyone.” One message per request, to confirm that the person signing in controls that number.
  • Only for sign-in. We do not send promotional text messages to this number.
  • Who delivers it: Covenant uses a text-message provider to deliver the code. The Privacy Policy names it and says what it receives.
  • Your number is private. It is how you sign in. It is never shown to another member.
